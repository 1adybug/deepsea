# @1adybug/components

[English](README.md) | [简体中文](README.zh-CN.md)

可复用 React 组件，覆盖尺寸驱动布局、滚动、文件流程、图表、媒体和视觉基础元素。

## 能力

- AutoFit、Flow、DraggableGrid、滚动效果、过渡与布局基础组件。
- 文件输入、电子表格控件、剪贴板交互、类型化 ECharts 与 HLS/WebRTC 播放。

## 安装与运行环境

```sh
pnpm add @1adybug/components
```

仓库开发使用 Node.js 24（>=24.15.0 且 <25）和 pnpm 11.10.0。下表给出本工作区声明的 peer 兼容范围，宿主应用应使用同一份对应运行时。

| Peer 依赖          | 工作区范围 |
| ------------------ | ---------- |
| `@types/node`      | `catalog:` |
| `@types/react`     | `^19.3.0`  |
| `@types/react-dom` | `^19.3.0`  |
| `react`            | `^19.3.1`  |
| `react-dom`        | `^19.3.1`  |

## 快速开始

```tsx
import { InputFile, Unify, UnifyConfigProvider } from "@1adybug/components"

function ImportPanel() {
    return (
        <UnifyConfigProvider className="p-4">
            <Unify as="section">
                <InputFile type="text" onValueChange={text => console.log(text)} />
            </Unify>
        </UnifyConfigProvider>
    )
}
```

## 行为与集成约束

交互组件应在提供 ResizeObserver 的浏览器中挂载，动画还可能依赖 requestAnimationFrame 或 Web Animations。AutoFit 测量已定位的父元素后显示内容。图表变体共享同一 ECharts 生命周期。RtspPlayer 接收 MediaMTX 的 HTTP(S) 播放地址并协商 WebRTC，不接收原始 rtsp:// 地址。HLS 与媒体支持取决于浏览器。

## 测试与开发

```sh
pnpm --filter @1adybug/components... build
pnpm --filter @1adybug/components test
pnpm --filter @1adybug/components test:types
```

全部公开组件及辅助函数：DOM 与属性行为、测量、交互、引用、定时器、文件失败、剪贴板、图表更新与销毁、媒体恢复与清理。第三方渲染引擎和 WebRTC 协商在集成边界使用替身。

从仓库根目录运行命令。完整检查与覆盖率说明见 [TESTING.zh-CN.md](../../TESTING.zh-CN.md)。
