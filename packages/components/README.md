# @1adybug/components

[English](README.md) | [简体中文](README.zh-CN.md)

Reusable React components for measured layouts, scrolling, file workflows, charts, media and visual primitives.

## Features

- AutoFit, Flow, DraggableGrid, scroll effects, transitions and layout primitives.
- File inputs, spreadsheet controls, clipboard actions, typed ECharts and HLS/WebRTC playback.

## Installation and requirements

```sh
pnpm add @1adybug/components
```

Repository development uses Node.js 24 (>=24.15.0 and <25) and pnpm 11.10.0. The table lists peer ranges declared by this workspace; the host should provide the corresponding shared runtime instances.

| Peer dependency    | Workspace range |

| `@types/node`      | `catalog:`      |
| `@types/react`     | `^19.3.0`       |
| `@types/react-dom` | `^19.3.0`       |
| `react`            | `^19.3.1`       |
| `react-dom`        | `^19.3.1`       |

## Quick start

```tsx
import { InputFile, Unify, UnifyConfigProvider } from "@1adybug/components"

function ImportPanel() {
    return (
        <UnifyConfigProvider className="p-4">
            <Unify as="section">
                <InputFile type="text" onValueChange={text => console.log(text)} />
            </Unify>
        </UnifyConfigProvider>
    )
}
```

## Behavior and integration

Mount interactive components in a browser with ResizeObserver. Animated components may also need requestAnimationFrame or Web Animations. AutoFit measures its positioned parent before showing children. Chart variants share one ECharts lifecycle. RtspPlayer expects a MediaMTX HTTP(S) playback URL and negotiates WebRTC; it does not accept a raw rtsp:// URL. HLS and media support depend on the browser.

## Tests and development

```sh
pnpm --filter @1adybug/components... build
pnpm --filter @1adybug/components test
pnpm --filter @1adybug/components test:types
```

All public components and helpers: meaningful DOM/prop behavior, measurements, interaction, refs, timers, file errors, clipboard, chart updates/disposal and media recovery/cleanup. Third-party rendering engines and WebRTC negotiation are mocked at their integration boundary.

Run commands from the repository root. See [TESTING.md](../../TESTING.md) for full checks and coverage reports.
